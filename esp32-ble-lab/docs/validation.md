自動テストは、バイト順・負値と単位換算・危険な角度と不正なチャンネルの拒否・通知形式チェック・GATT処理の直列化・切断中の指令破棄・再接続を対象にしています。
模擬BLEの画面テストは実際のブラウザーで実行しましたが、無線や実機タイミングを再現するものではありません。

ファームウェアの依存バージョン：

- espressif32 6.10.0 / Arduino ESP32 2.0.17
- NimBLE-Arduino 2.3.6
- Adafruit PWM Servo Driver Library 3.0.2
- Adafruit BusIO 1.17.4

実機ではREADMEの手順に従い、まずサーボを外した状態でI²CとIMUを確認してください。
続いて機構を外したサーボ1個を確認し、PWM停止・接続切断時・バックグラウンド時の停止を確認してください。
最後に機構へ取り付けて、負荷・可動範囲・電源容量に合わせて設定を調整してください。
